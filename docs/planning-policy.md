# Planning Policy

ProxyMorph planning work must be written down before implementation.

## Rule

For every future planning, design, roadmap, or implementation-plan discussion:

- Write the agreed plan to a document before starting implementation.
- Store design/spec documents under `docs/superpowers/specs/`.
- Store implementation plans under `docs/superpowers/plans/`.
- Keep the document updated when the user changes requirements.
- Reference the document in follow-up work so the project does not rely on chat memory.

## Current Preference

The user prefers durable planning documents for all future planning work.
